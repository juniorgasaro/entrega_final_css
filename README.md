# Home Studio 

## Sobre el proyecto

Home Studio es un sitio web de un estudio de grabación musical. La idea es mostrar los servicios que ofrecemos, presentar a nuestro equipo y compartir algunos de los trabajos musicales en los que participamos.

El sitio está pensado para que cualquier persona interesada en grabar, mezclar o masterizar su música pueda conocer nuestro trabajo y contactarnos.

## Páginas del sitio

El proyecto cuenta con 5 páginas:

- **Inicio:** presentación del estudio.
- **Servicios:** información sobre los servicios de grabación, mezcla y mastering.
- **Contacto:** medios para comunicarse con el estudio.
- **Nuestro equipo:** presentación de los equipos que forman parte de Home Studio.
- **Trabajos realizados:** muestra de algunos álbumes y proyectos musicales en los que trabajamos.

## Tecnologías utilizadas

Para desarrollar el sitio se utilizaron:

- HTML5 para la estructura y el contenido.
- SCSS para los estilos, utilizando variables, mixins, nesting, extend y partials.
- Bootstrap para los componentes responsivos.
- JavaScript para el funcionamiento de algunos componentes.
- AOS para incorporar animaciones al sitio.
- Media Queries para adaptar el diseño a celulares, tablets y computadoras.

## Diseño y características

El sitio cuenta con un diseño adaptado a diferentes tamaños de pantalla, una navegación responsiva, animaciones y una identidad visual relacionada con el mundo de la música y la grabación.

También se trabajó en la optimización SEO de las páginas para mejorar su presentación en los buscadores.
